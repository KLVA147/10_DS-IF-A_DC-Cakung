# Proyek Akhir Praktikum Data Science

## Pengelompokan Pola Gerak dan Aktivitas Manusia Berdasarkan Sinyal Smartphone Menggunakan Agglomerative Hierarchical Clustering

**Kelompok 10 - DC Cakung**

### 1. Ringkasan Proyek

Proyek ini merupakan Proyek Akhir Praktikum Data Science 2026/2027 yang bertujuan untuk mengelompokkan pola gerak dan aktivitas manusia berdasarkan sinyal sensor smartphone.

Dataset yang digunakan adalah UCI Human Activity Recognition (HAR) Using Smartphones Dataset, yang berisi data hasil pengukuran sensor accelerometer dan gyroscope pada smartphone.

Metode yang digunakan adalah Agglomerative Hierarchical Clustering, yaitu salah satu metode Unsupervised Learning yang digunakan untuk mengelompokkan data berdasarkan kemiripan karakteristiknya.

Proyek ini mencakup tahapan Business Understanding, Data Gathering, Exploratory Data Analysis (EDA), Cleaning dan Preprocessing, Modelling, Evaluasi, serta Konklusi.

### 3. Sumber Data

**Nama Dataset:** Human Activity Recognition Using Smartphones Dataset

**Sumber:** UCI Machine Learning Repository

**Tautan Dataset:** https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones

Dataset ini berisi data aktivitas manusia yang dikumpulkan menggunakan sensor accelerometer dan gyroscope pada smartphone.

Terdapat enam kategori aktivitas dalam dataset, yaitu:

- Walking
- Walking Upstairs
- Walking Downstairs
- Sitting
- Standing
- Laying

Dataset digunakan untuk menganalisis karakteristik pola gerak manusia dan melakukan pengelompokan aktivitas menggunakan metode Agglomerative Hierarchical Clustering.

### 4. Panduan Menjalankan Proyek

1. Clone atau download repository proyek ini.
2. Pastikan dataset UCI HAR tersedia pada direktori yang sesuai dengan path yang digunakan dalam notebook.
3. Buka file `Main.ipynb` menggunakan Jupyter Notebook atau Google Colab.
4. Pastikan library Python yang diperlukan sudah terpasang.
5. Jalankan setiap cell notebook secara berurutan dari awal hingga akhir untuk melihat keseluruhan proses analisis, preprocessing, pemodelan, evaluasi, dan kesimpulan.
